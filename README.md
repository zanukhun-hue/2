# NULL OBJECT

Портфолио проекта про плагины After Effects, эдиты и моушн-дизайн. Рабочая область адаптируется под десктоп и телефон. Визуальный референс — [Camiedrip](https://camiedrip.com/).

[Открыть сайт на GitHub Pages](https://zanukhun-hue.github.io/2/)

## Навигация

- Сайт открывается на английском. Переключатель **EN / RU** в верхней панели сохраняет выбранный язык в браузере.
- Выбирайте композицию в панели Project или на таймлайне. Клавиши **1–4** переключают разделы, а **Space** запускает и приостанавливает воспроизведение таймлайна.
- В главной композиции можно выбрать один из трёх треков и запустить его кнопкой **Слушать**.
- В разделе **Edits** выберите один из трёх роликов. У плеера есть перемотка, управление звуком и полноэкранный режим. Клавиша **Esc** закрывает полноэкранный режим или возвращает к постеру.
- Сайт показывает запасную графику, если основная обложка или аватар недоступны.

## Локальный просмотр

Запустите статический сервер из корня проекта.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Откройте [локальный сайт](http://127.0.0.1:8000/).

## Контент и публикация

Название проекта, треки, работы и ссылки редактируются в [site-config.js](site-config.js). Описание и подписи на обоих языках находятся в `PORTFOLIO_LOCALES` в том же файле. Обложки, видео и аудио хранятся в [assets](assets/).

[GitHub Actions](.github/workflows/pages.yml) проверяет синтаксис JavaScript и публикует статический сайт при изменениях в `main`. В настройках репозитория **Settings → Pages → Build and deployment** источником должен быть **GitHub Actions**.
